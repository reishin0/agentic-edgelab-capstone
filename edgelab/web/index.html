How to read ETF entry costs

Match the time
On each sampled morning, the model uses the same second in New York for all three ETFs. It picks the first second when each full purchase fits the size limits in both scenarios.
Read costs in dollars and basis points
One basis point (bp) is 0.01%. The quoted spread is the gap between the bid and ask. The study measures purchase cost against the midpoint value of the whole shares purchased.
Compare base and stress
Base uses the quoted ask, 1 bp of adverse slippage and a $1 commission. Stress doubles the distance from midpoint to ask and uses 5 bp of slippage with the same commission.
Check the scope
These are simulated purchase costs for the saved mornings. The study measures entry costs only.

Capstone checkpoints
November 2026

      

        
The six required course assignments guide the development of one capstone agent.
          Each applies a module’s concepts to the project and builds toward the final report and presentation.
          Program outline
        

        

          1.1
Project scoping and initial agent design

          

            
Course objective Define the problem, who the agent serves and what it should do.

            
EdgeLab Scoped an LM Studio assistant to help researchers assess long-run price
              relationships, with Python handling the calculations. In the reported synthetic run, Ornith supplied
              one structured choice. EdgeLab saved two eligible protocol candidates and stopped for approval.

          

        

        

          2.1
Agent design refinement

          

            
Course objective Refine how the agent makes decisions, what it remembers and which
              tools it uses.

            
EdgeLab The design added ReAct-style branching, budgets and a ledger to retain each
              trial when a failed prerequisite redirects work. The implemented CLI requires approval of the exact
              saved run and protocol digest before execution. LiteLLM role routing, cloud-to-local failover and
              native LangGraph checkpointing remain deployment options.

          

        

        

          3.1
RAG and retrieval design

          

            
Course objective Choose what knowledge the agent should retrieve, how it finds it and
              how it uses source evidence to ground its decisions.

            
EdgeLab Added reviewed, versioned method notes and source locators. Planning defaults
              to bundled notes. Optional Pinecone planning fetches ADF, KPSS and Engle–Granger by exact ID and
              verifies them against the reviewed corpus. Missing or mismatched evidence leaves the plan unresolved.
              The dashboard diagnostic verified all three exact records. Its separate semantic ranking found only KPSS.

          

        

        

          4.1
Tree-of-Thought integration

          

            
Course objective Decide where exploring several reasoning paths may help, how to
              compare and prune them, and how to test the benefit.

            
EdgeLab Confined Tree-of-Thought to planning to prevent outcome leakage. Beam search
              ranks protocols before seeing asset labels or observations, using width two, four levels and up to
              21 visits. Eligible protocol digests are saved for approval. A comparison with step-by-step planning
              on independently judged cases remains open.

          

        

        

          5.1
Multi-agent architecture and coordination

          

            
Course objective Define each agent’s responsibilities, what information they share and
              how they coordinate their work.

            
EdgeLab Put the Planner, Critic and Reporter under one controller. The benchmark
              evaluated the advisory roles in isolation on 24 blinded synthetic cases with equal model-call budgets.
              CrewAI scored 30.21% and the single agent scored 28.13%. The 2.08-percentage-point gain missed the
              10-point gate.

          

        

        

          6.1
Safety guardrails and human intervention

          

            
Course objective Identify failure modes, set guardrails and evaluation measures, and
              define when a human must intervene.

            
EdgeLab Defined interventions for ambiguous scope, evidence failures and uncertain
              tool state. A reservation without a result blocks replay and dependent calls. An operator can request
              a read-only handoff from the CLI. A hard-guard breach blocks promotion.

            
Pilot targets Capture 100% of mandatory escalations, keep unnecessary escalations at
              or below 15%, stop safely or recover on 100% of fault fixtures, and keep planning p95 under four
              minutes. The pilot plan calls for measuring human review wait separately.

            
Gateway demonstration The bundled loopback MCP Gateway served verified synthetic
              reports and recovered an operator-approved draft save after a lost response. The operator verified
              the original backend receipt before resuming. Scientific approval and execution stay in the CLI,
              and the market holdout remains locked.
